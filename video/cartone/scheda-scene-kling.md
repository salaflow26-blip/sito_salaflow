# Scheda scena per scena: InVideo → Kling 3.0 Video

**Impostazioni uguali per tutte:** modello **Kling 3.0 Video**, formato **16:9**, durata **5 s**, audio **spento**.

**Negative prompt** (se c'è il campo, sempre questo):

```
realistic, 3D render, photo, text, letters, words, subtitles, speech bubble, watermark, logo, extra limbs, extra fingers, face distortion, morphing, melting, blurry
```

Salvate ogni clip come `scena-01.mp4`, `scena-02.mp4`, ecc.
Le scene 11, 25 e 26 non si fanno: le monto io.
